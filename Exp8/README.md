# Experiment 8: Text Summarization

**Aim:**
1. Analysing the meaning of sentences.
2. Implement text summarization on the IMDB Movie Reviews dataset.

**Dataset:** [IMDB Dataset of 50K Movie Reviews - Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

**Topics:** Word sense disambiguation (Lesk), semantic role labelling, first-order logic, extractive summarization (word-frequency and TextRank)

**Libraries:** nltk, spacy, scikit-learn, networkx, pandas, matplotlib
